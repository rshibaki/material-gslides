プライバシーポリシー

material-gslides（以下「本ツール」）は、利用者が自分のパソコンで動かす個人用のツールです。

取得する情報

本ツールは、利用者の許可を得て Google ドライブの drive.file スコープを使い、本ツールが作成した Google スライドと一時ファイルだけを作成・編集・削除します。利用者が自分で作成したほかのファイルは読みません。

情報の保存と送信

Google から受け取った許可の情報（アクセストークン）は、利用者のパソコンの中にだけ保存します。本ツールの作者や第三者のサーバーに、利用者のデータや許可の情報を送ることはありません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

許可の取り消し

利用者は Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへの許可を取り消せます。
